# Breach Point

A browser tactical shooter: solo against bots, a training range, and online Team Deathmatch or Free-for-All with friends.

**Play:** https://proplat28.github.io/Breach-Point/

Online play is peer-to-peer. Players find each other through public Nostr relays, then connect directly over WebRTC. Host a match, share the code (or have friends pick it from the list), and play. No accounts needed.
